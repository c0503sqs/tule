# tule（涂乐）第一版设计

日期：2026-11-10
状态：待确认

## 意图

做一个 3-4 岁孩子能自己拿起来玩的 iPad 涂色游戏。第一版不做完整产品，只验证一件事：孩子会不会被"点一下、颜色铺满"和"自己乱涂"这两种手感吸引，愿意玩下去。

名字：tule（涂乐）。

## 目标

- 打开即玩，不需要读字、不需要成人引导。
- 填充模式：点画面中的空白区域，颜色铺满该区域，有一声"啵"和一次短暂的视觉脉冲（支持的设备上附带轻触感）。
- 涂鸦模式：选颜色后手指自由画粗线，画出边界也不惩罚。
- 3 张内置卡通线稿，可左右翻页。
- iPad 横屏、离线运行。

## 非目标（第一版不做）

- 用户传照片、AI 生成线稿。
- 保存作品、相册、分享。
- 完成奖励、动画庆祝、关卡。
- 撤销、橡皮、画布缩放。
- 设置、家长锁、统计、账号、联网。
- 上架 App Store、Android 打包（代码保持跨平台，但第一版只在 iPad 上验证）。

## 反目标

以下任何一条出现，即使功能正常也算失败：

- 孩子需要大人教才会用。
- 点下去颜色填满有卡顿感（超过 100ms 才出现）。
- 一次误触把整页涂满，孩子无法继续。
- 出现计时、分数、失败提示、弹窗或广告。
- 孩子找不到退出/翻页，或者误触直接退出应用。

## 成功标准

- 3-4 岁孩子拿到 iPad 后 5 秒内开始上色，无需说明。
- 连续玩 3 分钟以上，并主动要求翻下一页。
- 填充响应主观上"立刻出现"。
- 线稿的封闭区域不会被颜色漏到相邻区域；点到背景或漏色区域时画面保持不变。

## 关键决定

- **技术栈**：Flutter 3.47.x stable，iPadOS 17+，横屏锁定。同一套代码以后可出 Android 平板版。
- **上色引擎**：栅格洪水填充，不预先切分矢量区域。以线稿的黑色像素为墙，从手指落点向四周扩散。这样以后 AI 生成的任意线稿可以直接玩，不需要人工分区。
- **图层顺序**：白底 → 颜色层（填充色 + 涂鸦笔迹，透明底）→ 线稿层（黑线 + 透明底）。线稿始终压在最上面，孩子怎么涂都看得到轮廓。
- **每页两张位图**：原始线稿经预处理生成"透明底黑线"PNG；填充计算使用缩小到长边 1024px 的同一张图，绘制时放大显示。
- **背景规则**：人物周围连通的背景不参与填色。判定方法：填充区域只要触到图片四边，就判定为背景或漏色，整次取消，不改变画面。背景在应用里显示为淡米色纸面，和可涂的白色区域区分开。
- **无撤销**：只有"长按 1 秒重来本页"（垃圾桶图标，长按期间有进度环）。短按无反应，避免孩子误清空。
- **声音与反馈**：填充时一个短促的"啵"声，同时在落点闪一下白色脉冲（150ms）。涂鸦不发声，避免连续噪音。翻页无音效。iPad 没有 Taptic Engine，不依赖触感；`HapticFeedback` 只在支持的设备（如 iPhone）上自然生效，不作为必需反馈。
- **完成状态**：第一版没有"涂完"判断和庆祝动画。

## 交互布局（横屏）

```
┌──────────────────────────────────────────────┐
│  [填色] [涂鸦]                     [长按重来] │
│                                              │
│              ┌────────────────┐              │
│         ‹    │                │    ›         │
│              │   线稿画布      │              │
│              │                │              │
│              └────────────────┘              │
│                                              │
│    ●  ●  ●  ●  ●  ●  ●  ●  ●  ●              │
│               ● 页点 ●                        │
└──────────────────────────────────────────────┘
```

- 顶部两个大按钮切换模式，选中态明显（放大 + 白圈）。按钮上只有图标，无文字。
- 画布居中，保留边距，防止手指挡住边缘。画布纸面为淡米色，角色内部可涂区域保持白色。
- 底部 10 个大色块：红、橙、黄、绿、青、蓝、紫、粉、棕、黑。选中色块放大并出现白圈。
- 只用左右两个大按钮翻页，画布上不响应横向滑动，避免涂鸦时误翻页。共 3 页。
- 页点不可点击，只显示当前页。
- 默认进入填充模式，默认颜色为红色。
- 画布外点击无效。

## 填充算法细节

1. 页面加载时，把预处理后的线稿解码为长边 1024px 的 RGBA 像素。
2. 墙判定：像素 alpha > 40 视为黑线。对墙做一次 1px 膨胀，封住 AI 线稿的微小断口。
3. 落点如果落在墙上，向外找 8px 内最近的非墙像素；找不到就忽略。
4. 4 邻接扫描线洪水填充，得到区域像素集合。
5. 如果区域触到图片任意一边，判定为背景或漏色，取消本次填充，画面不变。
6. 把区域像素写入颜色层（相同 1024px 分辨率），用选中的颜色、alpha 255。
7. 颜色层转回 `ui.Image`，立刻重绘；同时播放"啵"声、闪一次落点脉冲。
8. 填充在 isolate 中执行，避免卡住 UI。

## 涂鸦细节

- 一条笔迹 = 手指按下到抬起的点序列，圆头圆角，线宽 22 逻辑像素。
- 直接累积在颜色层的同一张 `ui.Image` 上，或作为 `Path` 列表由 `CustomPainter` 绘制。
- 只允许单指；第二根手指忽略，避免孩子手掌误触产生乱线。
- 涂鸦不受线稿界线限制，但超出画布的部分裁掉，不覆盖顶部按钮和底部色块。

## 页面素材

- 3 张 AI 线稿已生成在 `assets/samples/`。
- 构建前用脚本 `tool/prepare_pages.py` 预处理：灰度 → 二值化（阈值约 170）→ 保留黑色线条并给透明背景 → 去掉浅灰阴影/腮红 → 输出到 `assets/pages/`。
- 原始图保留在 `assets/samples/`，预处理产物一并提交，运行时不依赖脚本。

## 工程结构

```
lib/
  main.dart                 // 入口、横屏锁定、主题
  coloring_page.dart        // 单页画布：图层、手势、模式
  flood_fill.dart           // 洪水填充（纯函数，可单测）
  palette.dart              // 颜色与色块组件
  page_turner.dart          // 翻页与页点
tool/prepare_pages.py       // 线稿预处理脚本
test/flood_fill_test.dart   // 填充边界与安全阀测试
assets/pages/*.png
assets/sfx/pop.wav
```

依赖：`audioplayers`（播放一个本地 wav）。不引入其他第三方包。

## 测试

- 单测：3x3 网格中间一圈墙，点中心只填中心；点角落不越墙；填充面积超过 50% 时返回失败。
- 单测：落点在线条上时找到邻近空白区。
- 真机验收：在 iPad 上逐条走"成功标准"和"反目标"。
