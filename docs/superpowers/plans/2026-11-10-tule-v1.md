# tule v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出能在 iPhone/iPad 上试玩的 tule 第一版：3 页卡通线稿，支持点选填色与自由涂鸦。

**Architecture:** Flutter 单页应用。线稿预先生成"黑线层 + 白色纸面层"两张 PNG。画布按白纸 → 颜色层 → 涂鸦笔迹 → 黑线层的顺序绘制。填色用栅格洪水填充：背景（与图片四边连通）不参与，填充区域碰到图片边界即取消。填充计算放在 isolate，结果写入 1024px 颜色层。

**Tech Stack:** Flutter 3.47.9 / Dart 3.13.7、audioplayers、Xcode 27.2、CocoaPods 1.17.0、Pillow 13（仅素材预处理）。

**Spec:** `docs/superpowers/specs/2026-11-10-tule-design.md`

## Global Constraints

- Flutter 命令统一先执行 `export PATH="/opt/homebrew/share/flutter/bin:$PATH"`。
- 目标设备 iPadOS 17+，只支持横屏。
- 唯一第三方依赖：`audioplayers`。不引入其他包。
- 3 页：`cat`（4:3）、`bear`（4:3）、`bunny`（1:1）。
- 10 个颜色：红 `0xFFE53935`、橙 `0xFFFB8C00`、黄 `0xFFFDD835`、绿 `0xFF43A047`、青 `0xFF00ACC1`、蓝 `0xFF1E88E5`、紫 `0xFF8E24AA`、粉 `0xFFEC407A`、棕 `0xFF8D6E63`、黑 `0xFF212121`。默认红色。
- 界面不出现文字；没有计时、分数、失败、弹窗、广告、联网、账号。
- 背景不可填；填充区域触到图片任意一边即整次取消。
- 只允许单指涂鸦；第二根手指及后续指针忽略。
- 无撤销、无存图、无完成动画；只有长按 1 秒重来本页。
- 颜色层与填充计算分辨率：长边 1024px。
- 本计划不包含 git 提交：用户未要求初始化仓库或提交。

## Review Focus

1. 点背景或图片边缘：画面必须完全不变，不发声、不出现半透明色块。
2. 直接点在黑线上：应吸附到附近的内部区域；找不到就当作无操作，绝不能把线条本身染色。
3. 涂鸦时手掌或第二根手指落下：只保留第一根手指的笔迹，不产生第二笔、不中断当前笔。
4. 连续快速点击或填充途中翻页：不崩溃、不把颜色写到错误的页面、不出现旧图覆盖新图。
5. 4:3 与 1:1 页面切换：点按位置与颜色区域必须对齐，图像不能拉伸变形。

```dart
class FillRegion {
  final Uint8List mask;      // width*height，1 = 属于填充区域
  final int area;
  final bool foundStart;
  final bool touchesBorder;
  const FillRegion({required this.mask, required this.area,

}

Uint8List computeBackgroundMask({
  required Uint8List rgba, required int width, required int height,
  int wallAlpha = 40,
});

FillRegion computeFillRegion({
  required Uint8List rgba, required int width, required int height,
  required int startX, required int startY,
```

- [ ] **Step 1: 写失败测试 `test/flood_fill_test.dart`**

```dart
import 'dart:typed_data';
import 'package:flutter_test/flutter_test.dart';
import 'package:tule/flood_fill.dart';

Uint8List wallsFromRows(List<String> rows) {
  final h = rows.length, w = rows[0].length;
  final data = Uint8List(w * h * 4);
  for (var y = 0; y < h; y++) {
    for (var x = 0; x < w; x++) {
      final i = (y * w + x) * 4;
      data[i + 3] = rows[y][x] == '#' ? 255 : 0;
    }
  }
  return data;
}

const ring = [
  '         ',
  '         ',
  '  #####  ',
  '  #   #  ',
  '  #   #  ',
  '  #   #  ',
  '  #####  ',
  '         ',
  '         ',
];

void main() {
  test('background mask marks border-connected area only', () {
    final bg = computeBackgroundMask(
        rgba: wallsFromRows(ring), width: 9, height: 9);
    expect(bg[0], 1);          // 角上是背景
    expect(bg[4 * 9 + 4], 0);  // 环内不是背景
  });

  test('enclosed region fills and does not touch border', () {
    final r = computeFillRegion(
        rgba: wallsFromRows(ring), width: 9, height: 9,
        startX: 4, startY: 4);
    expect(r.foundStart, isTrue);
    expect(r.touchesBorder, isFalse);
    expect(r.area, 9);
    expect(r.mask[4 * 9 + 4], 1);
    expect(r.mask[3 * 9 + 3], 1);
    expect(r.mask[0], 0);
    expect(r.mask[2 * 9 + 2], 0); // 墙上
  });

  test('tap on background does nothing', () {
    final r = computeFillRegion(
        rgba: wallsFromRows(ring), width: 9, height: 9,
        startX: 0, startY: 0);
    expect(r.foundStart, isFalse);
  });

  test('tap on a wall snaps to the enclosed side', () {
    final r = computeFillRegion(
        rgba: wallsFromRows(ring), width: 9, height: 9,
        startX: 2, startY: 4);
    expect(r.foundStart, isTrue);
    expect(r.area, 9);
    expect(r.touchesBorder, isFalse);
  });

  test('a gap large enough to leak makes the interior unfillable', () {
    final leaky = [
      '         ',
      '         ',
      '  #   #  ', // 3px 缺口，1px 膨胀后仍漏
      '  #   #  ',
      '  #   #  ',
      '  #   #  ',
      '  #####  ',
      '         ',
      '         ',
    ];
    final bg = computeBackgroundMask(
        rgba: wallsFromRows(leaky), width: 9, height: 9);
    expect(bg[4 * 9 + 4], 1); // 内部与外界连通，被判定为背景
    final r = computeFillRegion(
        rgba: wallsFromRows(leaky), width: 9, height: 9,
        startX: 4, startY: 4);
    expect(r.foundStart, isFalse);
  });

  test('applyRegionColor writes only masked pixels', () {
    final rgba = Uint8List(8); // 2 个透明像素
    final mask = Uint8List.fromList([1, 0]);
    applyRegionColor(rgba, mask, 0xFFFF0000);
    expect(rgba.sublist(0, 4), [255, 0, 0, 255]);
    expect(rgba.sublist(4, 8), [0, 0, 0, 0]);
  });

  test('normalizedToPixel clamps both ends', () {
    expect(normalizedToPixel(0, 0, 10, 20), (0, 0));
    expect(normalizedToPixel(1, 1, 10, 20), (9, 19));
    expect(normalizedToPixel(0.5, 0.5, 10, 10), (5, 5));
  });
}
```

- [ ] **Step 3: 实现 `lib/flood_fill.dart`**

算法要求：

1. `_walls(rgba, w, h, wallAlpha)`：`alpha > wallAlpha` 为墙。
2. 膨胀一次：任意墙像素的 4 邻域都变成墙（用于封住 1px 断口）。
3. `computeBackgroundMask`：从四边所有非墙像素做 4 邻接填充，标记为背景；返回 `Uint8List(w*h)`。
4. `computeFillRegion`：
   - `backgroundMask ??= computeBackgroundMask(...)`。
   - 起点必须在界内；若起点是墙或在背景里，按半径 1..`snapRadius` 的环形顺序找最近的、非墙且非背景的像素；找不到返回 `foundStart=false` 的空结果。
   - 用扫描线或队列做 4 邻接填充；遇到墙停止。
   - 填充过程中若碰到任意图片边界，把 `touchesBorder` 置 true。
   - 返回完整 mask、area、foundStart、touchesBorder。
5. `applyRegionColor`：遍历 mask，为 1 的像素写入 `colorArgb` 的 R/G/B 与 alpha 255。
6. `normalizedToPixel`：`floor(nx*width)` / `floor(ny*height)` 后 clamp 到 `[0,width-1]`、`[0,height-1]`。

- [ ] **Step 1: 实现资产加载**

2. 用 `ui.instantiateImageCodec` 解码全分辨率图。

`PageArtwork.create`：分配全 0 的 `colorPixels`，用 `ui.decodeImageFromPixels` 生成透明 `colorImage`，`strokes` 为空，`isFilling = false`。

- [ ] **Step 2: 实现画布绘制**

1. 背景透明（米色由外层容器提供）。
